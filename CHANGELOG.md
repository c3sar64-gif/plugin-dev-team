# Registro de cambios

## 0.2.0

- Cinco agentes revisores de solo lectura: arquitectura, C#, React, base de datos y seguridad.
- Tres agentes de trabajo: planificador, guía de pruebas y reparador de compilación.
- Skills `pruebas-backend`, `verificar` y `decisiones`.
- Comandos del flujo: `nueva-funcionalidad`, `revisar`, `nueva-migracion` y `commit`.
- Proyecto de ejemplo con errores sembrados para probar a los revisores.
